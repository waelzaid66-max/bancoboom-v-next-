# 1) تعريف المشكلة بدقة

## 1-أ · الفرق البنيوي — مقيس بالسطر

| القسم | `topBar` | `brandBlock` | العلاقة |
|---|---|---|---|
| **السيارات** | 229 | **245** | ✅ **ابن** |
| العقارات | 208 | 270 (بعد `</View>` في 267) | ❌ أخ |
| المواد | 114 | 166 | ❌ أخ |
| الحجز | 107 | 149 | ❌ أخ |

## 1-ب · ليه ده كان مشكلة

الفصل اللي نفّذناه للسيارات بيقسم الهيدر لشريحتين:

```
pinned  =  topBar + search          ← يفضل بره القائمة
scroll  =  hero + strips + stats    ← يروح جوه ListHeaderComponent
```

في السيارات البراند **جوه** `topBar` → فضل مثبّت ✅
في التلاتة البراند **بره** `topBar` → كان هينزل جوه القائمة، **تحت شرائح الفلاتر** ❌

**وده يخالف أمر المالك الحرفي:** `Do NOT change BANCO branding`.

## 1-ج · الافتراض الخاطئ اللي وقّفنا

**افترضنا إن الشريحة المثبّتة لازم تكون `topBar` بس.**

**ده افتراض مش قيد.** `SearchResultsSurface` مش بيهمه إيه اللي مثبّت — بيهمه بس إن اللي جوه `listHeader` يمشي مع الاسكرول.

**النتيجة:** المشكلة مكانتش بنيوية. كانت في تعريفنا للشريحة.

# 2) الحل — نموذج الشرائح الثلاث

بدل شريحتين، تلاتة:

```
pinned  =  topBar + brandBlock(مضغوط) + search
scroll  =  hero + strips + stats
```

**البراند بيفضل مثبّت من غير ما نحرّكه في الشجرة خالص.**

## 2-أ · ليه ده صحيح علميًا

| الشرط | الوضع |
|---|---|
| البراند فوق شرائح الفلاتر؟ | ✅ أيوة — في الشريحة المثبّتة |
| اتغيّرت الهوية؟ | ✅ لأ — نفس المكان النسبي، نفس الترتيب |
| اتغيّرت شجرة المكوّنات؟ | ✅ لأ — `brandBlock` فضل أخ لـ `topBar` زي ما هو |
| محتاج قرار المالك؟ | ✅ **لأ** |
| الشاشة اتحررت؟ | ✅ أيوة — الهيرو والشرائط راحوا للقائمة |

## 2-ب · التكلفة — ومعالجتها

الشريحة المثبّتة هنا **أطول** من السيارات، لأن `brandBlock` بياخد مساحة.

**القياس الفعلي (`PropertyHomeHeader.tsx:562-624`):**

```
brandBlock:
  wordmarkRow    ← شعار 32px + marginBottom 4        ≈ 36dp
  poweredLabel   ← fontSize 8 + marginBottom 1        ≈ 13dp
  poweredRow     ← صف الشعار                          ≈ 14dp
  marginBottom 4                                       ≈  4dp
  ─────────────────────────────────────────────────────────
  الإجمالي                                            ≈ 67dp
```

**تلات صفوف رأسية عشان يعرضوا سطر براند واحد.**

## 2-ج · ⭐ المفتاح — العيب هو الحل

**المالك شخّص العيب ده بنفسه في بريف الهيدرات:**
> «**POWERED BY سطر لوحده**»

يعني **ضغط البراند مطلوب أصلًا كإصلاح بصري** — مش تنازل عشان الفصل.

**الشكل المضغوط — صف أفقي واحد:**

```
[شعار 24px]  B-PROPERTIES  ·  powered by [BANCO]
```

```
brandLockup (مضغوط):
  صف واحد · ارتفاع الشعار 24 + padding رأسي 4      ≈ 28dp
```

**التوفير: 67dp → 28dp = 39dp مكسب، والبراند بيبقى أوضح مش أقل.**

## 2-د · الحساب النهائي للعقارات

| الشريحة | المحتوى | الارتفاع |
|---|---|---|
| **مثبّت** | topBar ≈ 48 · brandLockup ≈ 28 · search ≈ 54 | **≈ 130dp** |
| **متحرك** | هيرو + شرائط + إحصائيات | الباقي (~179dp) |
| **قبل** | كله مثبّت | **309dp** |

**المكسب: 309dp → ≈130dp مثبّت.** نفس رتبة مكسب السيارات (465 → 136).

# 3) التنفيذ — تعميم `slot` مش اختراع جديد

`CarsHomeHeader` عنده `slot` بقيمتين فعّالتين. التعميم بيضيف تالتة:

```tsx
slot?: "all" | "pinned" | "scroll";
const showPinned = slot === "all" || slot === "pinned";
const showScroll = slot === "all" || slot === "scroll";
```

**الفرق الوحيد عن السيارات:** `brandBlock` بيتحط تحت `showPinned` بدل ما يبقى جوه `topBar`.

```tsx
{showPinned ? (
  <>
    <View style={styles.topBar}>…</View>
    <View style={styles.brandLockup} testID="re-property-brand">…</View>
    <View style={styles.searchRow}>…</View>
  </>
) : null}

{showScroll ? (
  <>
    <View style={styles.hero}>…</View>
    …الشرائط والإحصائيات…
  </>
) : null}
```

## 3-أ · شروط إلزامية

| # | الشرط |
|---|---|
| 1 | `slot` الافتراضي **`"all"`** — أي مستدعي قديم يشتغل زي الأول بالظبط |
| 2 | **كل `testID` يفضل** — `re-property-brand` · `materials-core-brand` · إلخ |
| 3 | `paddingTop: slot === "scroll" ? 0 : topPad` |
| 4 | `testID` الجذر يتبدّل زي السيارات: `"<sec>-hero-band"` للمتحرك |
| 5 | ⛔ **ممنوع حذف أي عنصر** — الضغط = دمج صفوف، مش شيل محتوى |

## 3-ب · الحجز — فرق معماري

`BookingStaysApp` **مستقل عن** `SectionSearchApp` → لازم يمرر `listHeader` بنفسه لـ `SearchResultsSurface`.
**نفس النموذج، توصيل مختلف.**

## 3-ج · المصانع — بدون قيد أصلًا

`FacilitiesHomeHeader.tsx` **جديد** → يتبني بالبنية الصح من أول لحظة:
`brandLockup` مضغوط جوه الشريحة المثبّتة من البداية. **مفيش هجرة، مفيش مخاطرة.**

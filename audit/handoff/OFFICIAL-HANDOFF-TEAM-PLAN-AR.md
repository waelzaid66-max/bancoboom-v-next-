# 1) 📐 الخطة المرسومة

## 1-أ · البنية — قبل وبعد

```
❌ قبل — الهيدر أخ للقائمة، فبياخد شريحة ثابتة للأبد
┌──────────────────────────────┐
│  الهيدر (ثابت · 309–465dp)   │  ← مبيتحركش أبدًا
├──────────────────────────────┤
│  شرائح الفلاتر (صفّين)        │  ← ثابتة كمان
├──────────────────────────────┤
│  FlatList                    │
│   └ أول بطاقة تبدأ هنا 👎     │  ← عند 60% من الشاشة
└──────────────────────────────┘

✅ بعد — الشرائح الثلاث
┌──────────────────────────────┐
│  📌 مثبّت (≈130–136dp)        │
│    topBar + براند مضغوط + بحث │  ← البراند فوق دايمًا
├──────────────────────────────┤
│  FlatList                    │
│   ├ ListHeaderComponent      │  🔽 بيمشي مع الاسكرول
│   │   هيرو · شرائط · إحصائيات │
│   └ أول بطاقة 👍              │
└──────────────────────────────┘
```

## 1-ب · نموذج `slot` — التوزيع

```
                    ┌─────────────── slot ───────────────┐
                    │                                     │
              "pinned"                               "scroll"
                    │                                     │
        ┌───────────┼───────────┐              ┌──────────┼──────────┐
     topBar    brandBlock    search          hero      strips     stats
        A       (مضغوط)         C              B          D          E
```

**الافتراضي `"all"` = A+B+C+D+E مع بعض = السلوك القديم بالظبط.**
**عشان كده مفيش مستدعي قديم بيتكسر.**

## 1-ج · الاكتشاف اللي فكّ العقبة

```
السيارات ✅                        العقارات ❌
──────────────                    ──────────────
<topBar>          229             <topBar>         208
  <brandBlock>    245  ← ابن        …
</topBar>                         </topBar>        267  ← قفل
                                  <brandBlock>     270  ← أخ
```

**الافتراض الغلط:** «الشريحة المثبّتة = `topBar` بس».
**الحقيقة:** `SearchResultsSurface` **مبيهموش** إيه المثبّت — بيهمه بس اللي جوه `listHeader`.

**فوسّعنا المثبّت يشمل البراند. خلاص. مفيش قرار مطلوب.**

## 1-د · مسار الموجات

```
الموجة 1 ─ سريعة، متوازية، مخاطرة صفر
   A: ضغط أزرار الدول        B: شيل الادعاءات + تعريب الحجز
              └──────── بوابة ────────┘
                         ↓
الموجة 2 ─ الهيدرز

   A: العقارات (الأكبر)   ──► يستفيد من دروسه
              └──────── بوابة ────────┘
                         ↓
الموجة 3 ─ الباقي
   A: المواد        B: الحجز + هوية الاستيراد
              └──────── بوابة ────────┘
                         ↓
الموجة 4 ─ بعد قرارات المالك
   توحيد الأحمر (2) · Reanimated (4) · لوحة العقارات (5) · الخرائط (بحث)
```

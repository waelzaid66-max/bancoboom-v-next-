# 2) التصادمات وكيف حُلّت — للمراجعة

## ت-١ · `package.json` (halo/main × الزميل) — اتحاد
كل واحد ضاف اختبارات مختلفة. الحل: **اتحاد** — سلسلة `test` فيها الاتنين (presence/assistant من main + map-chrome/geo-area/section-neutrals من الزميل). **صفر اختبار اتشال.**

## ت-٢ · `CarsHomeHeader.tsx` (الزميل × أنا) — دمج أوتوماتيكي **سليم**
الزميل حوّل النيوترالز لـ`SECTION_NEUTRAL`؛ أنا أعدت البنية (لوحة/شريط/انكماش). git وفّق بينهم أوتوماتيكياً. **تحققت يدوياً:**
- النيوترالز كلها `SECTION_NEUTRAL.*` (لا hex بالإيد) → **حارس النيوترالز عدّى**.
- شغلي البنيوي نجا (15 مرجع لـ`HERO_PLATE`/`shellPlate`/`heroCollapse`/`marketSlot`).
- `SECTION_NEUTRAL.void = "#090909"` = نفس قيمتي → التدرّجات مطابقة.

## ت-٣ · `SectionSearchApp.tsx` (الزميل × أنا) — دلالي، حُلّ بقرار مكتوب
التصادم كان في تصميم كل قسم. الحل يحترم كل قسم زي ما اتراجع:
```
السيارات   → مثبّتة، بتنكمش (carScrollY)         — تصميمي (راجعه المالك)
العقارات   → propertyScrollY                     — الزميل
المواد     → materialsScrollHeader في القائمة    — الزميل
المصانع    → facilitiesScrollHeader + facilitiesScrollY — أنا
```
`listHeader = materialsScrollHeader ?? facilitiesScrollHeader` · `scrollY` يغطّي الأربعة. **قسم واحد mounted في المرة، فالسلسلة تحسم صح.**

## ت-٤ · فرع الزميل نفسه بيتعارض مع `main` الحالي
مش بس معايا — فرع الزميل **محتاج rebase على `main`** برضه (package.json/قناة). التجميع حلّها، بس **الأوديتور لازم يعرف إن أي فرع لوحده مش بيدمج نضيف على main دلوقتي.**

# 4) ترتيب الدمج المقترح على `main` (قرار المالك/المدير)

```
1. halo-e1biie          → main   (api-server fix · صفر تصادم · يقفل «typecheck 0»)
2. الأوديتور يراجع أ-1..أ-3
3. لو عدّى: claude/integration-all → main   (الباقي كله دفعة واحدة، متجمّع ومختبر)
   لو الأوديتور رفض حارس: نرجّعه على الفرع ونعيد التجميع
```

**ليه `integration-all` دفعة واحدة؟** لأن الفرعين (بتاعي والزميل) بيتصادموا على ملفين، ودمجهم منفصلين على main **هيعيد التصادم على main نفسه**. التجميع حلّه مرة واحدة ومختبر — **دمجه دفعة واحدة أأمن من دمج كل فرع لوحده.**
